# 学业与课程 DDL 订阅日历

这是一个由 GitHub Actions 自动化维护的标准日历订阅源（iCalendar / .ics），可以直接在 iPhone、iPad、Android 手机系统日历中订阅。

## 手机订阅地址

仓库部署到 GitHub Pages 后，订阅地址为：
`https://yyf419314-hub.github.io/my-ddl-calendar/ddl.ics`

---

## 手机订阅操作

### 1. 苹果设备（iPhone / iPad）
1. 打开系统自带 **日历** App。
2. 点击底部 **日历** -> **添加日历** -> **添加订阅日历**。
3. 粘贴上述订阅地址，点击 **订阅**。
4. 刷新频率建议设置为 **每小时** 或 **每天**，并打开提醒开关。
5. 可以在手机主屏幕或锁屏上添加系统自带的日历小组件，实时显示最近 DDL。

### 2. 安卓设备
- **Google 日历**：
  在电脑端或网页端打开 Google 日历，左下角「其他日历」点击 `+` -> **通过网址添加**，输入上述链接。手机端 Google 日历 App 会自动拉取同步。
- **国产安卓系统（小米/华为/OPPO/vivo等）**：
  打开系统自带「日历」-> 设置 -> 「日程导入」或「添加网络/URL订阅日历」，粘贴链接即可。

## 如何添加或修改 DDL

只需要修改仓库中的 `ddl_list.json` 文件：

```json
[
  {
    "title": "任务名称",
    "deadline": "2026-11-20 23:59:00",
    "description": "备注说明",
    "course": "课程名称"
  }
]
```

提交后，GitHub Actions 会在 1 分钟内自动更新日历，手机将在下一次自动刷新时同步最新内容。
